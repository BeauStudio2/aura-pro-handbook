Human and agent interfaces

Give each participant the information and actions appropriate to their role.

On this pageInputs and outputsApproachHow it worksTechnology choicesIntegration and native ownershipWhere this capability is usedConnected capabilities

Inputs and outputs

Inputs
The participant’s question, work context, permissions, and evidence available at the time.
Expected output
A useful next action, a source-backed answer, or a request delivered to the authorized decision maker.

Across the architecture

Construction tools, data ownership, and migration ↗

Approach

Present the next decision in the place the responsible person already works. Give a worker the instruction and check, an owner the alternatives and authority request, and an analyst the sources and uncertainty. The same scoped service contracts can support a human interface or an authorized software agent.

How it works

A foreman follows a link from a project issue to the current lift instruction. The link resolves the user's present rights and the latest revision. The owner's decision view includes options, cost, source documents, and the commitment being requested. An agent can draft a proposed change or retrieve an authorized record; consequential commands use the same authority checks as the human path.

Technology choices

Use the existing React/TypeScript/TanStack interface. Expose versioned JSON contracts for queries, drafts, and commands. Deep-link to Procore records where users already have accounts. Portable alternatives include a responsive standalone portal, reviewed PDF packets, and a documented HTTP API. Each connector maps client identities to scoped Aura Pro participants. Procore webhook behavior

Integration and native ownership

Let the client keep its familiar entry points while Aura Pro supplies cross-tool context. Adopt native role-specific workspaces where people benefit from fewer handoffs. Test a revoked link, a participant with access to only one work package, and an agent retrying a submitted command. An accessible link must never imply authority to approve.
