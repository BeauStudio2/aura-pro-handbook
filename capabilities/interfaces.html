Human and agent interfaces

What does each person need to see and do without reconstructing the whole project?

Give each participant the information and actions appropriate to their role.

In Mission Logic: AP presents the evidence, question, and permitted next action to the relevant participant. People can inspect the reasoning, correct its inputs, and make the decisions they retain; authorized agents use the same permission boundaries.

Approach

Present the next decision in the place the responsible person already works. Give a worker the instruction and check, an owner the alternatives and authority request, and an analyst the sources and uncertainty. The same scoped service contracts can support a human interface or an authorized software agent.

How it works

A foreman follows a link from a project issue to the current lift instruction. The link resolves the user's present rights and the latest revision. The owner's decision view includes options, cost, source documents, and the commitment being requested. An agent can draft a proposed change or retrieve an authorized record; consequential commands use the same authority checks as the human path.

Technology choices

The management view lets an owner or executive follow a measure to its work, evidence, assumptions, and decision owner. They can challenge the comparison or introduce another course without changing the approved plan.

AP provides a React/TypeScript/TanStack interface and versioned JSON contracts for queries, drafts, and commands. Direct links open Procore records where users already have accounts. Portable alternatives include a responsive standalone portal, reviewed PDF packets, and a documented HTTP API. Each connector maps client identities to scoped Aura Pro participants. Integration and native ownership

The client keeps familiar entry points while AP supplies cross-tool context. Teams adopt AP’s role-specific workspaces where fewer handoffs make the work easier. Test a revoked link, a participant with access to only one work package, and an agent retrying a submitted command. An accessible link must never imply authority to approve.
