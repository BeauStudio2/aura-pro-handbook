Project memory and learning

Retain the reasons, evidence, and conditions that can improve a later decision.

On this pageInputs and outputsApproachHow it worksTechnology choicesIntegration and native ownershipWhere this capability is usedConnected capabilities

Inputs and outputs

Inputs
Expected and observed outcomes, failed attempts, changed preferences, and expert explanations.
Expected output
Retrievable history and lessons whose scope and uncertainty travel with them.

Across the architecture

Construction tools, data ownership, and migration ↗

Approach

Keep the expectation, alternatives available at the time, action taken, evidence, and observed result together. Record why the case was selected for investigation. A useful lesson describes the conditions under which it transfers, including counterexamples.

How it works

Years after the lift, a facilities manager asks how to replace the unit. Retrieve dated dimensions, the panels held back, subsequent modifications, and remaining gaps. A new survey corrects the current condition and preserves the original installation history. Compare actual commissioning with the forecast; a different delay can invalidate a date while the measured clearance remains reliable.

Technology choices

Use the app's durable records plus an asynchronous retrieval projection. The project has exercised selected Mnemonic evidence handover in staging. PostgreSQL full-text search with evidence references is a simpler substitute; an optional embedding index can retrieve candidates. Enforce current access on every retrieval and support portable exports. Import Raken field history and Sage costs with source dates, units, and permissions. Raken client API · Sage Intacct construction API

Integration and native ownership

Own the retrieval and explanation first. Later own reviewed procedures and calibrated prediction inputs. Evaluate with held-out jobs and retrieval questions whose correct answer is “unknown.” A replacement manager must see permitted history and an outgoing manager must lose access according to current grants.
